# Code of Conduct

AM Auto Clicker contributors are expected to keep discussions constructive and respectful.

Examples of unacceptable behavior include personal attacks, harassment, discriminatory language, deliberate disruption, and publishing another person's private information without permission.

Project maintainers may edit or remove comments that violate these expectations and may close discussions when needed. Report conduct concerns by opening an issue that does not expose private information, or use GitHub's available reporting tools.
